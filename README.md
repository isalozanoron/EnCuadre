# EnCuadre

Servicio de alarmas para cinéfilos: dos productos de software complementarios (una app móvil y un sitio web) que cumplen el mismo objetivo del usuario en momentos distintos. Proyecto de la entrega de UI/UX de la maestría (MISO), curso de Diseño de Experiencia de Usuario.

**Equipo:** Isabella Lozano y Juan F. Rodríguez.

## Organización del repositorio

Este es **un solo repositorio**, dividido en **dos ramas independientes**, una por plataforma. La rama `main` (esta) está vacía a propósito y solo sirve como punto de entrada; todo el código vive en las otras dos ramas.

| Rama | Plataforma | README |
|---|---|---|
| [`EnCuadre-Web`](https://github.com/isalozanoron/EnCuadre/tree/EnCuadre-Web) | Angular + Angular Material | [Ver README](https://github.com/isalozanoron/EnCuadre/blob/EnCuadre-Web/README.md) |
| [`EnCuadre-Mobile`](https://github.com/isalozanoron/EnCuadre/tree/EnCuadre-Mobile) | Android nativo (Java) | [Ver README](https://github.com/isalozanoron/EnCuadre/blob/EnCuadre-Mobile/README.md) |

Cada rama tiene su propio README con las tecnologías, versiones, instrucciones para correr el proyecto, y el listado completo de pantallas implementadas por cada integrante.

Para clonar y trabajar en una plataforma específica:

```bash
git clone https://github.com/isalozanoron/EnCuadre.git
cd EnCuadre
git checkout EnCuadre-Web      # o EnCuadre-Mobile
```
